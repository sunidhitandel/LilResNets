# LilResNets
ResNets that are light on resources, heavy on performance!

### Project Overview
The goal of this project is to create lightweight ResNet variants with <5M parameters using ablation studies. We explore the impact of different network components—such as residual connections, layer depth, and filter sizes—while ensuring that we don’t compromise on accuracy or efficiency.

These models are designed to be fast, efficient, and perfect for environments where resources are limited, delivering high performance without breaking the bank.
